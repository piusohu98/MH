# MH 项目总计划

更新日期：2026-08-13

## 1. 产品目标

MH 是一个面向梦幻西游手游交易行的 Windows 本地市场监控与辅助决策工具。它通过合规获得的行情快照建立跨区、跨时间的价格历史，识别供需变化和节日效应，并以可解释、带置信度的方式给出观察或囤货建议。

产品不承诺获利，也不把推断值描述成官方数据。所有建议都必须能回溯到输入数据、计算窗口、规则版本和历史回测结果。

## 2. 安全与合规边界

允许：

- 用户主动提供的截图、截图目录和录制帧离线回放。
- 屏幕可见内容的本地 OCR、聚合统计和趋势分析。
- 模拟数据、人工标注数据和获得授权的数据导入。
- 人工确认后的白名单页面导航。

禁止：

- 自动买卖、自动定价或替用户执行交易。
- 破解或绕过验证码、登录保护和更新流程。
- 抓包、协议逆向、内存读取、进程注入或修改游戏数据。
- 在没有真实样本时编造窗口坐标、识别精度或在线采集完成度。

登录、更新、验证码、掉线或未知页面一律进入停止状态并通知人工处理。24 小时无人值守处理属于后续独立评估项，不进入当前实现范围。

## 3. 可回答的问题与指标定义

### 3.1 物价趋势

每个区服和商品保存原始观察值及日线聚合，展示开、高、低、收、可见数量、异常标记、短中期均线、动量和波动率。趋势结论必须附数据覆盖时间、样本量和新鲜度。

### 3.2 节日与活动经验

按事件类型保存活动窗口，比较活动前、活动中、活动后的价格和供给变化。跨区学习使用相同商品或类别的标准化收益率，并以非活动窗口和历史同期作为基线。训练、调参与回测严格按时间切分，禁止使用预测时点之后的数据。

### 3.3 囤货建议

建议不是单一涨跌预测，而是由以下证据组合：

- 价格偏离：当前价相对 7/30 日稳健中位数的位置。
- 趋势强度：短中期动量及其一致性。
- 供需代理：可见挂单量、页面数量、挂单消失速度和补货速度。
- 事件影响：相似历史事件的方向、幅度、稳定度和样本数。
- 流动性与风险：成交代理、波动率、价差、异常值占比和数据新鲜度。

输出动作限定为“观察、候选买入、持有、候选卖出、回避”，同时给出置信度、理由、失效条件和最大建议仓位。数据门槛不足时只输出“数据不足”。

### 3.4 区服人数指标

屏幕行情无法得知官方在线人数，因此工具只提供“活跃度估计指数”，不声称是具体真实人数。可用代理包括单位时间新增挂单、页面深度、价格修改频率、挂单消失率、峰谷时段差异及持续活跃天数。只有取得可校准的外部真实样本后，才允许把指数映射为人数区间，并展示误差范围。

### 3.5 老板/高消费玩家指标

“土豪数量”同样定义为高价值需求代理指数：高价品类的挂单消失速度、尾部高价成交代理、活动期间高价值品需求弹性、稀缺品流动性和价格冲击恢复速度。输出为低/中/高及置信度，不能输出未经校准的具体人数。

## 4. 五阶段路线

### 阶段 1：工程与数据闭环

- 建立 Core、Server、Client、Collector、Tests 五项目。
- 建立 SQLite 数据模型、模拟行情、基础 API 和幂等上传。
- Release 构建与集成测试通过。

状态：已完成可运行 MVP；正式 EF Migration 文件仍需补充，详见 `STATUS.md`。

### 阶段 2：分析与行情面板

- MAD 异常过滤、日/周聚合、7/30 日指标、波动与流动性指标。
- 可解释建议规则、置信门槛、仓位上限、确定性回测。
- WPF 总览、走势图、建议榜、活动日历、区服指标和个人仓位。
- 覆盖无未来数据泄漏、数据不足和断网降级测试。

状态：MAD、7/30 日指标、供给/新鲜度指标和纯 Core `recommendation-rules-v1` 已完成；滚动回测、回测启用门槛、建议 API 与 WPF 面板待完成。

### 阶段 3：OCR 与悬浮查价

- 集成 RapidOcrNet 中文模型和本地截图识别。
- 商品目录模糊匹配，低置信度显示候选项而不静默猜测。
- `Ctrl+Alt+M`、透明置顶悬浮窗、多显示器和 DPI 定位。
- 截图不上传，目标 P95 本地查询时间不超过 1.5 秒。

### 阶段 4：采集器离线闭环

- 截图目录和录制帧回放、采集状态机、断点恢复。
- 白名单导航接口和人工处理通知。
- 登录、更新、验证码、掉线、未知页面立即停止操作。
- 从模拟帧到 SQLite、API、分析和悬浮查询的端到端测试。

### 阶段 5：真实适配预留

- 输出截图采集规范、脱敏要求和标注格式。
- 实现只观察不点击的窗口捕获模式。
- 收到真实账号环境和原始截图后再建立坐标模板、页面分类器和精度基线。
- 完成自包含 Windows 发布和用户验收说明。

## 5. 总体验收标准

- Release 全解法构建、自动化测试和自包含发布全部通过。
- SQLite 模拟行情能驱动 API、分析、WPF、OCR 调试和悬浮查价。
- 数据不足、离线、OCR 低置信度、掉线、验证码及未知页面均安全降级。
- 所有模型和建议均记录版本、输入窗口、置信度和理由。
- 不包含自动交易、验证码破解、抓包、内存读取或游戏数据修改。
